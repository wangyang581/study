> 对应课程：[01 模板语法](../src/views/Lesson01Template.vue)

## 1. 先搞清楚：Vue 到底解决了什么问题？

传统的页面开发（jQuery 时代）是这样写的：

```js
// 命令式：一步步告诉浏览器怎么做
const count = 0
$('#btn').click(function () {
  count++
  $('#num').text(count)      // 手动更新文字
  if (count > 10) {
    $('#tip').show()         // 手动控制显隐
  } else {
    $('#tip').hide()
  }
})
```

数据一多，这种代码就变成了「在 10 个地方更新 10 个 DOM」，任何一处漏了都出 bug。

Vue 的写法是这样：

```vue
<script setup>
import { ref } from 'vue'
const count = ref(0)
</script>

<template>
  <button @click="count++">+1</button>
  <p>{{ count }}</p>
  <p v-if="count > 10">已经超过 10 了</p>
</template>
```

**你只描述「数据和界面的对应关系」，Vue 负责在数据变化时把界面更新到正确状态。**
这叫**声明式渲染**，是 Vue 最核心的价值。

### 三个关键词

| 概念 | 含义 |
| --- | --- |
| **响应式（Reactivity）** | 数据变了，Vue 能「知道」，并自动更新用到它的地方 |
| **声明式渲染** | 描述结果（`{{ count }}`），而不是过程（`$('#num').text(count)`） |
| **组件（Component）** | 把页面拆成独立、可复用、可组合的小块 |

## 2. 本项目的技术栈与各自的职责

| 工具 | 作用 | 类比 |
| --- | --- | --- |
| **Vue 3** | 视图层框架：响应式 + 组件 | 汽车的发动机 |
| **Vite** | 开发服务器 + 打包工具 | 车间 + 生产线（提供热更新 HMR） |
| **Vue Router** | 前端路由：地址 ↔ 页面 | 导航系统 |
| **Pinia** | 跨组件共享状态 | 中央储物柜 |
| **npm** | 包管理器 | 零件仓库 |

注意：**Vite 和 Vue 不是一回事**。Vite 是构建工具（也支持 React/Svelte），
Vue 是框架。之所以常一起出现，是因为它们的作者相同、配合最顺。

## 3. 项目结构逐个文件解释

```
vue/
├── index.html          ← 唯一的 HTML 页面
├── vite.config.js      ← 构建配置
└── src/
    ├── main.js         ← JS 入口
    ├── App.vue         ← 根组件
    ├── router/         ← 路由表
    ├── components/     ← 通用组件
    ├── views/          ← 页面级组件
    ├── composables/    ← 可复用逻辑
    └── stores/         ← 全局状态
```

### `index.html`

```html
<div id="app"></div>
<script type="module" src="/src/main.js"></script>
```

整个应用只有这一个 HTML 文件，里面只有一个空 div。
**这是 SPA（单页应用）的特征**：页面切换不重新加载 HTML，而是用 JS 换掉 div 里的内容。

### `main.js`（入口）

```js
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'
import router from './router'
import './styles/main.css'

const app = createApp(App)   // 1. 创建应用实例
app.use(createPinia())       // 2. 安装插件
app.use(router)
app.mount('#app')            // 3. 挂载到 #app 节点
```

记住这三步：**创建 → 装插件 → 挂载**。

### `.vue` 文件 = 单文件组件（SFC）

一个 `.vue` 文件最多包含三块：

```vue
<script setup>
// ① 逻辑：数据、方法、生命周期
</script>

<template>
  <!-- ② 结构：HTML + Vue 指令 -->
</template>

<style scoped>
/* ③ 样式：scoped 表示只作用于本组件 */
</style>
```

`<script setup>` 是 Vue 3 的**语法糖**：里面定义的变量、函数，
模板里可以直接用，不用 `export default { ... }` 那一套（那是选项式 API）。

> 也有 `<style lang="scss">`、`<script>`（不带 setup）等变体，后面会遇到。

## 4. 第一个概念：响应式数据 `ref`

```js
import { ref } from 'vue'

const count = ref(0)      // 创建响应式数据
console.log(count.value)  // 脚本里读写要 `.value`
count.value++             // 触发更新
```

```vue
<template>
  <p>{{ count }}</p>      <!-- 模板里自动解包，直接写 count -->
</template>
```

**为什么要有 `.value`？**
因为 Vue 需要拦截「读」和「写」这两个动作，才能知道什么时候该更新界面。
对于基础类型（数字、字符串、布尔），JS 没法拦截变量本身，
所以用一层包装对象 + `.value` getter/setter 来实现。

在模板里，Vue 的编译器会自动帮你解包，所以看起来更自然。

> 更深入的原理见 [03 响应式](03-响应式-计算属性-侦听器.md)。
