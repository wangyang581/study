# 10 · 练习与进阶路线

## 一、分级练习题

按难度递增。**强烈建议每题都动手写**，写不出来就回对应课程重看。

### 🟢 入门（对应第 01~07 课）

1. **个人名片页**：头像、姓名、简介、技能标签（用 `v-for` 渲染标签）。
2. **温度转换器**：输入摄氏度，实时显示华氏度（`computed`）。
3. **简单计算器**：加/减/乘/除，带「清空」和错误提示（除以 0）。
4. **Todo（静态版）**：添加 / 删除 / 勾选完成，但**不涉及组件拆分**。
5. **成绩单**：输入多门课成绩，显示平均分、最高分、及格率（`computed` + `v-for`）。
6. **Tab 切换 + 弹窗**：练习 `v-if` / `v-show` / `@click.self`。

### 🟡 进阶（对应第 08~14 课）

7. **组件化 Todo**：拆成 `TodoInput` / `TodoList` / `TodoItem`，用 props + emit。
8. **评分组件**：支持 `v-model`、半星、只读模式、`max` 可配置。
9. **模态框组件**：`v-model` 控制显隐、`#header` / `#footer` 插槽、Esc 关闭、点击遮罩关闭、
   打开时锁定 body 滚动。
10. **折叠面板（Accordion）**：多个面板，支持单选/多选展开，带过渡动画。
11. **表格组件**：`columns` 用 props 传，单元格用作用域插槽自定义，
    支持排序和分页。
12. **搜索框**：防抖 300ms + 竞态处理 + loading/空/错误三态。
13. **图片懒加载**：用 `IntersectionObserver` 封装成 `useIntersection` composable。
14. **拖拽排序列表**：原生 drag 事件或 `vuedraggable`，带 `.list-move` 动画。

### 🔴 综合（对应第 15~17 课）

15. **多页面后台**：路由 + 嵌套布局 + 侧边栏高亮 + 面包屑 + 权限守卫。
16. **完整 Todo 应用**：
    - 组件拆分 + Pinia + 路由（全部/未完成/已完成 三个路由）
    - 持久化、撤销删除（Undo）、批量操作
    - 截止日期 + 逾期高亮 + 分组显示
17. **仿某网站首页**：导航、卡片流、加载更多、骨架屏、回到顶部按钮。
18. **表单引擎**：根据配置数组动态渲染表单（文本/数字/下拉/开关），
    带校验和错误提示。
19. **主题系统**：亮/暗/跟随系统三种模式，用 CSS 变量 + Pinia + localStorage。
20. **音乐播放器**：播放列表、进度条、音量、循环模式（练习 `ref` 操作真实 DOM）。

## 二、用「一个小项目」检验自己

学完之后，挑一个真实需求做完整实现。推荐从这三个里选：

| 项目 | 练到什么 |
| --- | --- |
| **个人博客（前端部分）** | 路由、Markdown 渲染、列表+详情、分页、SEO 基础 |
| **后台管理系统** | 嵌套路由、权限、表格、表单、图表集成、Pinia |
| **在线待办 / 记事本** | 全流程、持久化、离线、PWA |

**完成标准**（不是"能跑"就行）：

- [ ] 有完整的加载 / 空 / 错误状态
- [ ] 组件拆分合理，单个文件不超过 300 行
- [ ] 移动端可用
- [ ] 刷新不丢状态（必要的地方做持久化）
- [ ] 有 README 说明如何运行
- [ ] 部署到线上（Vercel / Netlify / GitHub Pages）

## 三、接下来该学什么？

按优先级排序：

### 1. TypeScript（最优先）

Vue 3 对 TS 支持极好，中大型项目基本都用 TS。学会：

- 基础类型、interface、泛型、联合类型
- `defineProps<{ title: string }>()`、`defineEmits<{ (e: 'change', v: number): void }>()`
- `ref<string>()`、`computed<number>()`
- 类型收窄、工具类型（`Partial`、`Pick`、`Omit`）

```vue
<script setup lang="ts">
import { ref, computed } from 'vue'

interface User { id: number; name: string; email?: string }

const props = defineProps<{ users: User[]; loading?: boolean }>()
const emit = defineEmits<{ (e: 'select', user: User): void }>()

const keyword = ref<string>('')
const filtered = computed<User[]>(() =>
  props.users.filter(u => u.name.includes(keyword.value))
)
</script>
```

### 2. 单元测试

- **Vitest** + **@vue/test-utils**：组件测试
- 学习重点：测试行为而不是实现、mock 网络请求（`vi.mock`）、
  `flushPromises` 处理异步、覆盖率不是目标

### 3. 组件库与工具集

- **VueUse**：`useLocalStorage`、`useMouse`、`useIntersectionObserver`、
  `useDebounceFn` 等上百个 composable —— **强烈推荐**，能省下大量代码
- **Element Plus / Ant Design Vue / Naive UI**：中后台常用
- **Tailwind CSS / UnoCSS**：原子化 CSS，写页面很快
- **Iconify / unplugin-icons**：图标方案

### 4. 工程化深化

- **Vite 深入**：插件机制、环境变量、构建优化、代码分割
- **Monorepo**：pnpm workspace、turborepo
- **CI/CD**：GitHub Actions 自动 lint / test / build / 部署
- **Docker**：容器化部署
- **Nginx**：静态资源、反向代理、gzip/brotli

### 5. 服务端与全栈

- **Nuxt 3**：Vue 的全栈框架（SSR / SSG / 文件路由 / 服务端接口）
- **SSR / SSG 概念**：为什么需要、和 SPA 的区别、hydration
- **Node.js / Hono / Nitro**：写自己的 API

### 6. 其他方向

| 方向 | 内容 |
| --- | --- |
| 可视化 | ECharts、D3、Three.js |
| 富文本 | Tiptap、ProseMirror |
| 低代码 | 动态表单、Schema 驱动渲染、拖拽搭建 |
| 微前端 | qiankun、Module Federation |
| 性能 |  Core Web Vitals、打包分析、首屏优化 |
| 跨端 | uni-app、Taro、Electron、Tauri |

## 五、给「从后端转前端」的同学

如果你是后端出身，下面这张对照表能帮你快速迁移心智：

| 后端概念 | 前端 Vue 对应 |
| --- | --- |
| 变量 / 字段 | `ref` / `reactive` |
| 计算属性 / 视图 | `computed`（数据库视图的类比很贴切） |
| 监听器 / 触发器 | `watch` |
| 类 / 实体 | 组件（`.vue` 文件） |
| 构造函数参数 | `props` |
| 回调 / 事件 | `emit` |
| 依赖注入 | `provide` / `inject` |
| 单例 / 全局缓存 | Pinia store |
| 路由（后端） | Vue Router |
| 序列化 / DTO | props 的类型声明、API 层 |
| 生命周期 / 中间件 | 生命周期钩子、路由守卫 |

**最大的思维转变**：不要想「先这样、再那样地操作 DOM」，
而是想「数据是什么样，界面就长什么样」。**先设计数据，界面自然就出来了。**

## 六、最后

> 前端的门槛在「入门」，天花板在「细节」。

- 入门：会写组件、会调接口、会路由 —— 本教程的 17 课应该够了
- 进阶：性能、可访问性、工程化、架构设计 —— 需要在真实项目中磨练
- 高手：能判断「这个需求该不该做、怎么做才最简单」 —— 靠经验和审美

**不要只学框架。** CSS 布局、浏览器渲染原理、HTTP、事件循环、JS 基础，
这些「不变的东西」比任何框架都重要。框架会换，基础永存。

祝学习顺利 🎉
