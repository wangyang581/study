## 1. `<style scoped>` 的原理

```vue
<style scoped>
.title { color: red; }
</style>
```

编译后大致变成：

```css
.title[data-v-7ba5bd90] { color: red; }
```

同时模板里的元素会被加上 `data-v-7ba5bd90` 属性。
于是样式只命中本组件的元素 —— **原理是属性选择器，不是 Shadow DOM**。

### 想影响子组件？用 `:deep()`

```vue
<style scoped>
/* 父组件想改子组件内部的 .title 样式 */
.parent :deep(.title) { color: red; }
/* 或者 */
.parent :deep(.child-item) { ... }
</style>
```

其他相关伪类：`:slotted(selector)`（针对插槽内容）、`:global(selector)`（全局）。

> 最佳实践：**尽量不用 `:deep()`**，它破坏了封装。更好的做法是通过 props / CSS 变量
> 让子组件自己支持定制。

### `scoped` 的边界情况

- 子组件的**根元素**会同时带上父组件的 `data-v-xxx`，所以父组件的 scoped 样式能命中它
- 用 `v-html` 渲染出来的内容**不会**带 scoped 属性，样式不生效 → 需要用 `:deep()` 或全局样式

## 2. `:class` 三种写法

```vue
<!-- ① 对象：开关类名 -->
<div :class="{ active: isActive, 'text-red': hasError }"></div>

<!-- ② 数组：组合多个 -->
<div :class="['box', sizeClass, { active: isActive }]"></div>

<!-- ③ 三元 -->
<div :class="['box', isActive ? 'active' : '']"></div>

<!-- 和静态 class 合并（最终会被合并，不会覆盖） -->
<div class="box base" :class="{ active: isActive }"></div>
```

**命名注意**：对象键含连字符时要用引号 `{ 'text-red': true }`。

## 3. `:style` 三种写法

```vue
<!-- 对象 -->
<div :style="{ color: activeColor, fontSize: size + 'px' }"></div>

<!-- 数组：后面的覆盖前面的 -->
<div :style="[baseStyles, overrideStyles]"></div>

<!-- 直接写 -->
<div :style="{ width: progress + '%' }"></div>
```

- 属性名用 **camelCase**（`fontSize`）或 **kebab-case 字符串**（`'font-size'`）
- Vue 会自动给数值补 `px`（除了 `opacity`、`z-index`、`flexGrow` 等无单位属性）
- 自动加厂商前缀（`-webkit-` 等）

## 4. CSS 变量做主题（强烈推荐）

这是最轻量、最实用的主题方案：

```js
const THEMES = {
  light: { bg: '#fff', text: '#24292f', accent: '#42b883' },
  dark:  { bg: '#1e293b', text: '#f1f5f9', accent: '#38bdf8' },
}
const theme = ref('light')
const themeVars = computed(() => ({
  '--panel-bg': THEMES[theme.value].bg,
  '--panel-text': THEMES[theme.value].text,
  '--panel-accent': THEMES[theme.value].accent,
}))
```

```vue
<div class="panel" :style="themeVars">...</div>
```

```css
.panel { background: var(--panel-bg); color: var(--panel-text); }
.panel button { background: var(--panel-accent); }
```

好处：**只改一个 style 对象，整个子树的配色都变**，不用逐个组件传 props。

配合 `prefers-color-scheme` 还能做「跟随系统」：

```css
@media (prefers-color-scheme: dark) {
  :root { --bg: #1e293b; }
}
```

## 5. 过渡 `<Transition>`

Vue 会在进入/离开时自动添加固定的 CSS 类：

```
进入：xxx-enter-from  →  xxx-enter-active  →  xxx-enter-to
离开：xxx-leave-from  →  xxx-leave-active  →  xxx-leave-to
```

`name` 默认为 `v`：

```vue
<Transition name="fade">
  <p v-if="show">内容</p>
</Transition>
```

```css
.fade-enter-from { opacity: 0 }
.fade-enter-active { transition: opacity .4s ease }
/* .fade-enter-to 通常不需要写（等于默认状态） */

.fade-leave-active { transition: opacity .4s ease }
.fade-leave-to { opacity: 0 }
```

### 常用属性

| 属性 | 作用 |
| --- | --- |
| `name` | 类名前缀 |
| `appear` | 初次渲染也播放进入动画 |
| `mode="out-in"` | 旧的先离开，新的再进入（互斥切换） |
| `mode="in-out"` | 反之 |
| `:duration="300"` | 显式指定时长（会影响移除时机） |
| `:css="false"` | 关闭 CSS 检测，改用 JS 钩子 |

### 多元素过渡

`<Transition>` 内**只能有一个根元素**。多个互斥元素要用 `v-if`/`v-else` +
`mode="out-in"`，并给每个元素加 `key`。

```vue
<Transition name="fade" mode="out-in">
  <component :is="currentView" :key="currentView" />
</Transition>
```

## 6. 列表过渡 `<TransitionGroup>`

用于 `v-for` 列表的增删和移动：

```vue
<TransitionGroup name="list" tag="ul">
  <li v-for="item in items" :key="item.id">{{ item.text }}</li>
</TransitionGroup>
```

```css
.list-enter-from { opacity: 0; transform: translateX(-24px) }
.list-leave-to   { opacity: 0; transform: translateX(24px) }
.list-enter-active, .list-leave-active { transition: all .4s ease }

/* 关键 1：离开的元素脱离文档流，其他元素才能"让位" */
.list-leave-active { position: absolute; width: 100%; }

/* 关键 2：位置变化的元素会获得 -move 类 */
.list-move { transition: transform .4s ease; }
```

没有 `.list-move` 时，其他元素会「瞬间跳」到新位置，看起来生硬。

### 交错动画（stagger）

```css
.list-enter-active { transition-delay: calc(var(--i) * 40ms); }
```
```vue
<li v-for="(item, i) in items" :key="item.id" :style="{ '--i': i }">
```

## 7. JS 钩子与动画库

```vue
<Transition
  @before-enter="onBeforeEnter"
  @enter="onEnter"
  @after-enter="onAfterEnter"
  @leave="onLeave"
  :css="false"
>
```

```js
function onEnter(el, done) {
  gsap.to(el, { y: 0, opacity: 1, onComplete: done })  // 必须调用 done()
}
```

**什么时候需要动画库**：时间线编排、物理弹性（spring）、SVG 路径动画、
滚动驱动动画（GSAP ScrollTrigger、Framer Motion、motion.dev）。
简单入场/列表动画 → **优先 CSS**，性能更好且不增加体积。

### 性能提示

只动画 **`transform` 和 `opacity`**（走 GPU 合成层，不触发重排）。
避免动画 `width`/`height`/`top`/`left`（每帧重排，会掉帧）。
需要动画尺寸时考虑 `transform: scale()` 或 FLIP 技巧。

## 8. 页面开发实用技巧

```css
/* 1. 现代布局首选 Flex / Grid */
.row { display: flex; align-items: center; gap: 12px; }
.grid { display: grid; grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); gap: 16px; }

/* 2. 盒模型统一用 border-box（务必全局设置） */
* { box-sizing: border-box; }

/* 3. 让长文本自动省略 */
.ellipsis { overflow: hidden; text-overflow: ellipsis; white-space: nowrap; }
.clamp-2 { display: -webkit-box; -webkit-line-clamp: 2; -webkit-box-orient: vertical; overflow: hidden; }

/* 4. 等宽数字，避免数字变化时抖动 */
.num { font-variant-numeric: tabular-nums; }

/* 5. 加载中特效 */
.skeleton { background: linear-gradient(90deg,#eef2f6 25%,#e3e8ef 37%,#eef2f6 63%); background-size: 400% 100%; animation: shimmer 1.3s infinite; }

/* 6. 无障碍：尊重用户的"减少动画"偏好 */
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: .01ms !important; transition-duration: .01ms !important; }
}
```
