## 1. 插值：`{{ }}` 是「文本内容」专用

```vue
{{ message }}                  <!-- 变量 -->
{{ count * 2 }}                <!-- 表达式 -->
{{ ok ? '是' : '否' }}          <!-- 三元 -->
{{ name.toUpperCase() }}       <!-- 函数调用 -->
{{ list[0].title }}            <!-- 属性访问 -->
```

**限制**：

```vue
<!-- ❌ 只能是「单个表达式」，不能是语句 -->
{{ let x = 1 }}
{{ if (ok) { ... } }}

<!-- ❌ 不能用在属性位置，属性要用 v-bind -->
<img src="{{ url }}" />

<!-- ✅ 正确 -->
<img :src="url" />
```

表达式里能访问的东西：当前组件作用域内的数据、全局白名单（`Math`、`Date`、`JSON` 等）。
**访问不到 `window`**（这是有意设计，防止模板里乱写逻辑）。复杂逻辑请放到 `computed`。

## 2. 指令一览（Vue 3 最常用的 10 个）

指令就是带 `v-` 前缀的特殊属性。**指令的值是 JS 表达式**，不是字符串。

| 指令 | 简写 | 作用 | 示例 |
| --- | --- | --- | --- |
| `v-bind` | `:` | 绑定属性 | `:src="url"`、`:disabled="ok"` |
| `v-on` | `@` | 绑定事件 | `@click="fn"` |
| `v-model` | — | 双向绑定表单 | `v-model="text"` |
| `v-if` | — | 条件渲染（增删 DOM） | `v-if="ok"` |
| `v-else-if` / `v-else` | — | 条件分支 | — |
| `v-show` | — | 条件显示（切 display） | `v-show="ok"` |
| `v-for` | — | 列表渲染 | `v-for="item in list"` |
| `v-html` | — | 渲染 HTML 字符串 | `v-html="html"` |
| `v-once` | — | 只渲染一次 | `v-once` |
| `v-pre` | — | 跳过编译，原样显示 | `v-pre` |

### 动态参数

```vue
<a :[attrName]="value">链接</a>   <!-- attrName 是变量，如 'href' -->
<button @[eventName]="fn">按钮</button>  <!-- eventName 是变量，如 'click' -->
```

较少用，但写通用组件时会遇到。

## 3. 条件渲染：`v-if` vs `v-show`

```vue
<!-- v-if：条件为假时节点根本不存在 -->
<div v-if="loading">加载中</div>
<div v-else-if="error">出错了</div>
<div v-else>内容</div>

<!-- v-show：节点一直存在，只是切换 style="display:none" -->
<div v-show="loading">加载中</div>
```

| | `v-if` | `v-show` |
| --- | --- | --- |
| 切换开销 | 高（销毁/创建 DOM，触发组件生命周期） | 低（只改 CSS） |
| 初始开销 | 低（条件为假就不渲染） | 高（总要先渲染出来） |
| 能否与 `v-else` 配合 | 能 | 不能 |
| 适合 | 条件很少变、初始就不该渲染（权限内容） | 频繁切换（Tab、下拉、tooltip） |

**`<template>` 是「隐形包裹」**：想一次控制多个元素，又不想多一层 div 时用它。

```vue
<template v-if="ok">
  <h1>标题</h1>
  <p>正文</p>
</template>
```

> ⚠️ 不要在同一元素上同时用 `v-if` 和 `v-for`。Vue 3 中 `v-if` 优先级更高，
> 拿不到 `v-for` 的变量。正确做法是用 `computed` 先过滤数据。

## 4. 列表渲染与 `:key`（最重要的一节）

```vue
<li v-for="item in list" :key="item.id">{{ item.name }}</li>
<li v-for="(item, index) in list" :key="item.id">{{ index }} - {{ item.name }}</li>
<li v-for="(value, key, index) in obj" :key="key">{{ key }} = {{ value }}</li>
<span v-for="n in 10" :key="n">{{ n }}</span>   <!-- 1..10 -->
```

### 为什么必须有 `:key` 且必须是唯一 ID？

Vue 更新列表时，需要判断「新的这堆元素里，哪个是原来哪个」。
`key` 就是元素的身份证。

```vue
<!-- 数据：['A', 'B', 'C'] 渲染成 3 个输入框，用户在第 2 个框输入了 "x" -->
<!-- 现在删除第 1 项 -->
<li v-for="(item, i) in list" :key="i">      <!-- ❌ 用下标 -->
```

用下标当 key 时，Vue 认为「第 0 项还是第 0 项，只是内容变成了 B」，
于是**复用原来第 0 项的 DOM，包括里面输入框的状态**。结果就是输入的内容「串行了」。

用 `:key="item.id"` 时，Vue 知道「id=1 的没了」，于是精确地删掉那一个，其余保持不变。

**结论**：

- 用**业务数据里的唯一 ID**（后端通常都会返回 `id`）
- 没有 ID 时在数据进入前端时生成一个（如 `crypto.randomUUID()`）
- **不要用 index**（除非这个列表永远不会重新排序/删除）

### 数组的响应式更新

Vue 3 用 `Proxy` 实现响应式，所以下面这些都能正确触发更新：

```js
list.value.push(x)          // ✅ 都能侦测
list.value.pop()
list.value.splice(i, 1)
list.value.sort()
list.value.reverse()
list.value[0] = newItem     // ✅ Vue 3 也支持下标赋值（Vue 2 不支持）
list.value = newList        // ✅ 整体替换
list.value.length = 0       // ✅
```

## 5. 事件处理

```vue
<button @click="count++">+1</button>          <!-- 内联表达式 -->
<button @click="add(5)">+5</button>           <!-- 传参 -->
<button @click="handleClick">处理函数</button> <!-- 函数引用 -->
<button @click="add(5, $event)">带事件对象</button>
```

`$event` 是原生事件对象。注意区别：

- `@click="handle"` → 把函数本身传过去，Vue 用事件对象调用它
- `@click="handle()"` → 立即执行（在渲染时就会执行）**这是常见错误**

### 修饰符（高频！）

```vue
<form @submit.prevent="onSubmit">              <!-- 阻止默认行为（表单提交后不刷新页面） -->
<div @click.stop="...">                        <!-- 阻止冒泡 -->
<div @click.self="...">                        <!-- 只有点到自身才触发 -->
<button @click.once="...">                     <!-- 只触发一次 -->
<div @click.capture="...">                     <!-- 捕获阶段触发 -->
<div @scroll.passive="...">                    <!-- 不调用 preventDefault，滚动更顺 -->

<input @keyup.enter="search" @keyup.esc="close" />
<input @keydown.ctrl.s="save" />               <!-- 组合键 -->

<!-- 修饰符可以串联，顺序有意义 -->
<form @click.stop.prevent="...">
```

`.prevent` 的两种等价写法：

```vue
<button @click.prevent="fn">       <!-- Vue 帮你 preventDefault -->
<button @click="fn($event)">       <!-- 手动 e.preventDefault() -->
```

## 6. 表单绑定 `v-model`

`v-model` 是一个语法糖，展开后是 `:value` + `@input`：

```vue
<input v-model="text" />
<!-- 等价于 -->
<input :value="text" @input="text = $event.target.value" />
```

### 不同控件的绑定类型

| 控件 | 绑定类型 |
| --- | --- |
| `<input type="text">` | 字符串 |
| `<textarea>` | 字符串（**内容写在标签里，不要用 `{{ }}`**） |
| `<input type="checkbox">` 单个 | 布尔 |
| `<input type="checkbox">` 多个 | 数组（配合 `:value`） |
| `<input type="radio">` | 字符串（配合 `value`） |
| `<select>` 单选 | 字符串 |
| `<select multiple>` | 数组 |

```vue
<!-- 多个复选框：选中哪些，数组里就有哪些 value -->
<input type="checkbox" v-model="hobbies" value="编程" />
<input type="checkbox" v-model="hobbies" value="音乐" />

<!-- 单选 -->
<input type="radio" v-model="gender" value="male" />
<input type="radio" v-model="gender" value="female" />

<!-- 下拉多选 -->
<select v-model="skills" multiple>
  <option value="vue">Vue</option>
</select>
```

### 三个实用修饰符

```vue
<input v-model.lazy="x">     <!-- 输入时不更新，change 时才更新 -->
<input v-model.number="n">   <!-- 自动转 number（type="number" 仍可能拿到字符串） -->
<input v-model.trim="s">     <!-- 自动去首尾空格 -->
```

## 7. 常见坑

| 坑 | 现象 | 解决 |
| --- | --- | --- |
| 用 index 当 key | 删除后输入框内容错位 | 改用唯一 id |
| 模板里塞复杂逻辑 | 可读性差、重复计算 | 抽成 `computed` |
| `v-if` 和 `v-for` 同元素 | 报错/拿不到变量 | 先 `computed` 过滤 |
| 表单没加 `.prevent` | 点击提交整页刷新 | `@submit.prevent` |
| `@click="fn()"` | 渲染时就执行了 | `@click="fn"` 或 `@click="() => fn(x)"` |
| `:class="{ active: 'false' }"` | 永远为真（非空字符串） | 用布尔 `:class="{ active: isActive }"` |
